# Ades Putra 01 Store

Aplikasi E-Commerce Ritel Fashion Sepatu, Sandal, dan Tas Modern.

Tagline: *"Langkah Nyaman, Gaya Maksimal Setiap Hari"*  
Visi: *"Belanja Pasti Tanpa Ragu: Harga Promo, Kualitas Terbaik, Pengiriman Cepat!"*

---

## ✨ Fitur Unggulan
1. **Landing Page Visual Promo**: Showcase koleksi produk fashion (Sepatu Sneakers/Loafer Size 36-43, Sandal Slide Empuk, Tas Modern).
2. **Katalog Produk & Size Filter**: Pilihan ukuran kaki (Size 36 s/d 43) lengkap dengan detail promo dan stok real-time.
3. **Program VIP Membership (Rp 50.000)**: Instant 50.000 Koin Member cashback 100%, diskon khusus, dan garansi bebas retur size 7 hari.
4. **Checkout Terintegrasi**: Pilihan ekspedisi kurir (J&T Express, JNE Reguler, GOTO Instant 3 Jam, Ninja Xpress), pembayaran COD & QRIS, maps preview, dan direct order ke WhatsApp admin.
5. **AdesBot AI Assistant**: Konsultasi ukuran kaki (cm ke size 36-43) dan rekomendasi produk.
6. **Portal Pengelola (Admin)**: Manajemen produk (CRUD) dan grafik analisis penjualan mingguan.

---

## 🚀 Menjalankan Secara Lokal
```bash
npm install
npm run dev
```
Buka [http://localhost:3000](http://localhost:3000) di browser Anda.
